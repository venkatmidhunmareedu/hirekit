# Backend Engineer

## Job description
Tallowgate Systems is hiring a Backend Engineer for the team that runs its order and invoicing platform, a set of Python services behind a public REST API used by about 400 business customers.

You will design and build FastAPI services, model data in PostgreSQL, and ship changes through a container-based pipeline to a managed cloud. You will write the tests for what you build, review the code of others, and take your turn on the on-call rota.

What you will do:
- Build and evolve REST endpoints with clear contracts, validation and error handling.
- Design tables, indexes and migrations, and keep queries fast as data grows.
- Write unit and integration tests and keep the build green.
- Package services in containers and deploy them to the cloud.
- Add logging, metrics and alerts, and help diagnose production incidents.

What we look for: solid Python, a good grasp of relational databases, a habit of testing, and some experience running software in production. Cloud and operations depth is a plus, not a requirement.
